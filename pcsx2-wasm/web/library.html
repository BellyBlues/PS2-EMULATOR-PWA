Disc art is downloaded by serial from the ps2-covers collection on GitHub, unless the folder has an image named like PCSX2’s covers (SLUS-20946.jpg). Only the serial is sent.

This page only rehearses the insert. On the player page, the game would boot while the disc goes in, and its first frame would come up here.
